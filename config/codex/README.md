# Codex Adapter

Codex-specific files live here. Shared prompts and skills stay under `agents/`.

Install target examples:

- `AGENTS.md` -> `~/.codex/AGENTS.md`
- selected prompts -> `~/.codex/prompts`
- selected skills -> `~/.codex/skills`
- config template -> `~/.codex/config.toml.template`
- MCP template -> `~/.codex/mcp.json.template`
